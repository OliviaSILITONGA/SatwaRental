# SatwaRental - Struktur File yang Dipisahkan

Selamat datang! Kode telah berhasil dipisahkan menjadi file-file terpisah dengan struktur yang lebih rapi.

## 📁 Struktur Folder

```
SatwaRental/
├── index.html        ← Halaman utama (Landing Page)
├── barang.html       ← Halaman katalog/daftar barang
├── detail.html       ← Halaman detail barang
├── login.html        ← Halaman login
├── register.html     ← Halaman registrasi
├── tentang.html      ← Halaman tentang kami
├── syarat.html       ← Halaman syarat & ketentuan
├── styles.css        ← Semua style/CSS (digunakan semua halaman)
├── script.js         ← Script JavaScript bersama
└── README.md         ← File ini
```

## 📄 Penjelasan File

### HTML Files (Halaman)
1. **index.html** - Halaman utama dengan hero section dan featured items
2. **barang.html** - Katalog lengkap dengan search dan filter
3. **detail.html** - Detail produk dengan booking form
4. **login.html** - Form login untuk pengguna
5. **register.html** - Form registrasi akun baru
6. **tentang.html** - Halaman tentang kami dan tim
7. **syarat.html** - Halaman syarat & ketentuan

### CSS & JavaScript
- **styles.css** - Semua styling (CSS) digunakan oleh semua halaman
- **script.js** - Fungsi JavaScript bersama (data items, filter, toast, dll)

## 🔗 Navigasi

Semua halaman terhubung melalui:
- **Navigation Bar** di atas (link ke semua halaman)
- **Footer** (link navigasi di bawah)
- **Tombol-tombol** dalam konten halaman

## 💾 Cara Menggunakan

1. Buka file `index.html` di browser
2. Klik tombol/link untuk navigasi ke halaman lain
3. Semua halaman akan meload CSS dan JavaScript yang sama

## ✨ Fitur Utama

✅ Landing page dengan hero section  
✅ Katalog produk dengan search & filter  
✅ Halaman detail produk dengan booking form

## 🚀 Pengembangan Selanjutnya

Jika ingin menambahkan fitur baru:
- **Tambah halaman baru**: Buat file HTML baru + link di navbar
- **Ubah style**: Edit `styles.css`
- **Tambah fungsi**: Edit `script.js`
